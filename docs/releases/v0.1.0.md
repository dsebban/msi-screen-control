Initial release of MSI Screen Control for macOS 13+ and the MSI Modern MD342CQP (USB protocol V20).

- Menu-bar controls for full screen, PBP, input selection and swapping sides.
- Agent CLI with JSON results, dry-run planning and explicit, idempotent commands.
- Complete layout packets, five-second settling, full USB state verification and interprocess locking.
- Separate Apple silicon (`arm64`) and Intel (`x86_64`) app ZIPs, each containing `msi-screen` in `Contents/MacOS/`.
- MIT license; no firmware replacement or flashing.

The app is ad-hoc signed, **not Developer ID signed or notarized**. macOS may block a downloaded copy; build from source if you prefer. Checksums in `SHA256SUMS` verify the downloaded archives.

GitHub Actions runs unit tests, builds both architectures, validates bundle signatures and dependencies, and smoke-tests the CLI extracted from each ZIP. Hosted CI does not test a physical monitor or the menu UI. USB readback verifies monitor settings, not the physical picture.

PIP editing, brightness, volume and KVM routing are not implemented. See the README for USB upstream requirements, commands and hardware verification.
