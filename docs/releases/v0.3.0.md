# MSI Screen v0.3.0

- The Layout preview shows computer names, video ports, current versus draft layouts, and other assigned computers that are off screen. Keyboard and mouse controls use the monitor's verified whole-hub USB routing.
- Universal Control links appear on both configured Macs, including an off-screen Mac. Select the already linked Mac under **Connection & input management → Universal Control → Shared Mac**. The link records configuration; macOS owns the live connection.
- USB and Bluetooth peripheral inventory updates automatically. **Controls & agent support** exposes support requests for unknown devices while preserving the monitor controls. Interfaces are grouped by OS USB ancestry rather than product-name guesses.
- **Discovered via Tailscale** lists local, online and offline tailnet devices without changing saved assignments. Native Tailscale SSH and standard SSH are supported per computer. Network discovery does not identify monitor cables; assign each video port explicitly.
- The Linux computer physically connected to USB-B has an explicit saved assignment. Adding another Linux computer does not redirect the USB hub to it.
- Compact M-only menu-bar icon: muted grey when unavailable, source colors in full screen, and left/right colors in PBP.
- Controls float above other apps across Spaces. An unavailable monitor shows a neutral preview with disabled layout controls.
- Signed Sparkle updates download in the background. A yellow dot and an **Update ready** action appear when an update is staged; **Install…** opens the standard installer, or the update installs when you quit.
- App actions includes **Check for updates…**. Update relaunches wait for active monitor, display and mouse configuration operations to finish.
- **Settings → Launch at login** controls native macOS autostart. It defaults on once for the installed app, honors later changes, and shows when macOS requires approval.
- **Settings → Install agent skill** installs the bundled CLI instructions for compatible agents, preserving any existing differing skill.
- **Settings → Install ad-hoc support skill** installs the independent device-support authoring instructions. Local support metadata, activation management and agent handoffs are available; general experimental Read/plan/Apply execution remains qualification-gated. Detecting a device does not establish control support or physical input delivery.

Install this release manually once to enable future in-app updates. Earlier releases do not include an updater. Public installers remain universal, Developer ID signed and notarized; ad hoc CI packages are separate verification artifacts.

Saving machine configuration upgrades its registry to schema 3 for explicit SSH transport and USB-B ownership. Older releases refuse this newer schema; retain a configuration backup if you need to return to an older app.
