# MSI Screen v0.3.0

- Compact M-only menu-bar icon: muted grey when unavailable, source colors in full screen, and left/right colors in PBP.
- Controls float above other apps across Spaces. An unavailable monitor shows a neutral preview with disabled layout controls.
- Signed Sparkle updates download in the background. A yellow dot and an **Update ready** action appear when an update is staged; **Install…** opens the standard installer, or the update installs when you quit.
- App actions includes **Check for updates…**. Update relaunches wait for active monitor, display and mouse configuration operations to finish.
- **Settings → Launch at login** controls native macOS autostart. It defaults on once for the installed app, honors later changes, and shows when macOS requires approval.
- **Settings → Install agent skill** installs the bundled CLI instructions for compatible agents, preserving any existing differing skill.

Install this release manually once to enable future in-app updates. Earlier releases do not include an updater. Public installers remain universal, Developer ID signed and notarized; ad hoc CI packages are separate verification artifacts.
