MSI Screen v0.2.0 adds machine, USB KVM and peripheral controls for the MSI Modern MD342CQP (USB protocol V20).

- Redesigned menu-bar controls with live input and USB-host indicators, explicit full-screen/PBP routing, and saved layouts.
- Machines tab for named Macs and Linux computers, SSH status, Mac main/extended display roles and left/right laptop placement.
- USB-host controls in Machines and Peripherals; optional USB handoff when selecting a computer full screen. The Linux return path requires the documented companion and narrow USB permission rule.
- Nineteen model-specific monitor settings, including brightness, picture modes and speaker volume. HDR is reported signal status rather than a toggle.
- Logitech POP Keys/Bolt and Rapoo MT760 Pro/NearLink diagnostics, guarded mouse mappings, app/Spaces wheel actions and a pinned-app top button.
- Native macOS game-controller status and a bounded control test. Bluetooth controllers do not move with the USB hub; wired devices must support USB data mode.
- Read-only privacy validation in the UI and CLI, plus a stable signing identity for retaining grants across updates.
- Expanded machine-readable CLI discovery, stale-state guards and offline/hardware/GUI verification.

**Install:** download `MSI-Screen-v0.2.0-macos-universal.dmg`, open it, quit any running MSI Screen, and drag **MSI Screen.app** onto **Applications**. For an upgrade, replace the existing copy in its current Applications folder. Eject the disk and launch the installed app; its controls appear in the menu bar.

The universal app and DMG support Apple silicon and Intel Macs running macOS 13 or later. Both are **Developer ID signed and notarized**, with stapled Apple tickets. The universal ZIP contains the same notarized app. Verify downloads with `shasum -a 256 -c SHA256SUMS`.

Mouse features may require Accessibility and Input Monitoring. Upgrading from the ad hoc v0.1.0 build can require removing and re-adding MSI Screen once in those permission lists. Later builds must retain the same certificate-backed identity. Permissions are shown under **Peripherals → Privacy & permissions**.

Monitor writes are verified by protocol readback, which does not prove the physical picture. Physical Spaces switching and USB controller handoff remain separate acceptance checks. No firmware flashing, factory reset, or monitor restart is included.
