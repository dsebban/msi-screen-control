# MSI Screen v0.4.0

- **Connection** shows the active MSI resolution and refresh rate, available macOS modes, EDID and local video port diagnostics. Start and stop a bounded monitoring session to record connection, mode and port changes. Monitoring is opt-in and read-only.
- `msi-screen video` provides the same local diagnostics without USB or SSH. It remains usable when saved machine configuration is unavailable.
- `msi-screen connections` reads local video, USB control and configured computers independently, retaining useful partial results when a source is unavailable. Observed computer names, EDID identity and inferred HDMI topology stay separate from saved assignments and verified OSD layout.
- The bundled agent skill documents both new diagnostic paths. Linux status reads include validated EDID identification when available, with explicit errors for incomplete observations.

The universal app and DMG are Developer ID signed, notarized and stapled. Video diagnostics describe operating-system observations; they do not establish physical image quality or panel limits. Experimental device Read/plan/Apply remains qualification-gated.
